# Logs

One file per landed prompt, `NN-<name>.md`, in the template of the campaign README §5.1. Written
by the implementing agent in the same commit as its change. Nothing here is edited after the
fact; a later correction is a new subsection, dated. Scratch probes a prompt wants to keep go
beside its log in `NN-probes/`. Prompt 07's figures, built from synthetic records, go in
`07-figures/`.
